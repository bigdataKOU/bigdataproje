Problem ve Veri Seti

Veri seti: Chicago Crimes 2001–Present — Chicago Police CLEAR sistemi

  • ~7.9 milyon olay, 23 yıl, 22 kolon
  • Kolonlar: ID, Date, Block, Primary Type, District, Ward, Beat, Lat/Lon, Arrest, Domestic ...
  • Görev: Çoklu sınıf Primary Type sınıflandırması (PDF: "suç tipi ve bölge tahmini")
  • 35+ suç tipi var → Top-5 + OTHER = 6 dengeli sınıf
Chicago polisinin CLEAR sisteminden gerçek dünya verisi. 2001'den günümüze 7.9 milyon olay. Sınıf dengesizliği problemi var (THEFT %22, ARSON %0.1), bu yüzden top-5 + OTHER yaklaşımı.

Bronze · Silver · Gold

🥉 Bronze (raw event store)

  • Kafka crimes → Delta /opt/delta/bronze/crimes
  • Kritik fix: maxOffsetsPerTrigger=200000 (yoksa cluster dev batch'te commit etmiyor)
  • partitionBy(event_date)

🥈 Silver (ML-hazır)

  • dedup by id + null filtre (district, lat/lon, primary_type)
  • Türetilmiş: hour_of_day, day_of_week, month, event_year
  • partitionBy(event_year) — fan-out önleyici

🥇 Gold (analitik + ML feature view)

  • type_stats, district_stats, hourly_stats, feature_view
  • Delta OPTIMIZE compaction → 67K küçük parquet → 8.5K büyük
Medallion architecture: bronze raw, silver temizlenmiş + feature, gold agregat. Critical performance fix: bronze maxOffsetsPerTrigger. Tasarımca silver event_year (28 dizin) çünkü event_date 8K+ dizin yaratacaktı.

Feature Importance PDF Zorunlu

Random Forest split önemine göre en etkili özellikler:

  1. latitude + longitude — coğrafi konum suç tipini belirleyici
  2. hour_of_day — günün saati (theft gündüz, battery gece)
  3. district — Chicago ilçesi (north/south side farkı)
  4. community_area — daha ince konum granularity
  5. event_year — uzun vadeli trend (narcotics 2010 sonrası azaldı)

Tam grafik: docs/rapor.html → Feature Importance

Coğrafi koordinatlar ve zaman en güçlü sinyaller. Lokasyon × saat etkileşimi ağaç-tabanlı modellerin lineer modellerden iyi olmasının sebebi.
