Bronze · Silver · Gold

🥉 Bronze · raw event store

  • Kafka crimes → Delta append
  • partitionBy(event_date)
  • Fix: maxOffsetsPerTrigger=200K

🥈 Silver · ML-hazır

  • dedup by id + null filter
  • Türetilmiş: hour/dow/month/year
  • partitionBy(event_year)

🥇 Gold · analitik + ML feature view

  • type_stats — suç tipi başına frekans + arrest_rate
  • district_stats — ilçe başına en sık tip + lat/lon
  • hourly_stats — saat × suç tipi heatmap
  • feature_view — ML-hazır 13 özellik snapshot
  • eda_overview — EDA özet metrikleri
  • predictions — inference çıktısı

💡 Optimize: Silver shuffle + partitioning 67K küçük parquet üretiyordu → Delta OPTIMIZE ile 8.5K büyük dosyaya kompakt edildi

Medallion architecture netleştirme. Bronze raw, silver feature-ready, gold analitik. Bronze maxOffsetsPerTrigger fix ve silver OPTIMIZE — iki kritik performans iyileştirmesi.
